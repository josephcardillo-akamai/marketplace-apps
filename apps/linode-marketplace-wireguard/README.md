# Linode WireGuard Marketplace App

Deploy a secure and efficient VPN server using WireGuard. This Marketplace App automates the setup of a WireGuard VPN endpoint on your Akamai Compute instance, allowing you to establish secure, encrypted connections between your devices. WireGuard is a modern VPN protocol known for its simplicity, high performance, and strong cryptography.

The installation configures a single WireGuard server and allows for pre-configuration of one client peer. It sets up proper firewall rules, enables IP forwarding, and provides secure key management.

## Software Included

| Software  | Version   | Description   |
| :---      | :----     | :---          |
| WireGuard  | Latest    | Modern VPN protocol that provides fast, secure network tunneling. Uses state-of-the-art cryptography and is designed to be simpler and more performant than IPsec and OpenVPN. |
| UFW | Latest | Uncomplicated Firewall for managing network access rules and security. |
| Fail2Ban | Latest | Intrusion prevention system that protects against brute-force attacks. |

**Supported Distributions:**
- Ubuntu 24.04 LTS

## Configuration Options

| Option | Description |
| :--- | :--- |
| WireGuard Port | The UDP port WireGuard will listen on (default: 51820) |
| Server VPN Network | The private network range for your VPN (e.g., 10.0.0.1/24) |
| Client VPN IP | The specific IP address assigned to your client (e.g., 10.0.0.2/32) |
| Client Public Key | The WireGuard public key of your client device |
| Client Public IP | The public IP address where your client will connect from |

## Linode Helpers Included

| Name  | Action  |
| :---  | :---    |
| Update Packages   | The Update Packages module performs apt update and upgrade actions as root.  |
| UFW   | The UFW module will utilize a list generated by `linode_helpers/ufw/ufwgen.yml` in the `group_vars/linode/vars` and enables the service.  |
| Fail2Ban   | The Fail2Ban module installs, activates and enables the Fail2Ban service.  |
| Secure SSH | The Secure SSH module configures SSH security settings including disabling root login and password authentication when appropriate. |
| SSH Key | The SSH Key module manages SSH key deployment for the sudo user, supporting both custom public keys and account keys. |

## Post-Installation

After installation, you can find:
- WireGuard configuration at `/etc/wireguard/wg0.conf`
- Server's public key in `/etc/wireguard/public.key`
- Connection status can be checked with `wg show`

## Use our API

Customers can choose to deploy WireGuard through the Linode Marketplace or directly using API. Before using the commands below, you will need to create an [API token](https://www.linode.com/docs/products/tools/linode-api/get-started/#create-an-api-token) or configure [linode-cli](https://www.linode.com/products/cli/) on an environment.

Make sure that the following values are updated at the top of the code block before running the commands:
- TOKEN - Your Linode API token
- ROOT_PASS - Root password for the Linode
- USERNAME - System user that will be created
- WIREGUARD_PORT - Port for WireGuard (default: 51820)
- SERVER_PRIVATE_IP - Server's VPN network address
- CLIENT_PUBLIC_KEY - Client's WireGuard public key
- CLIENT_PRIVATE_IP - Client's VPN IP address
- CLIENT_PUBLIC_IP - Client's public IP address

```
SHELL:
export TOKEN="YOUR API TOKEN"
export ROOT_PASS="aComplexP@ssword"
export USERNAME="user1"
export WIREGUARD_PORT="51820"
export SERVER_PRIVATE_IP="10.0.0.1/24"
export CLIENT_PUBLIC_KEY=""
export CLIENT_PRIVATE_IP="10.0.0.2/32"
export CLIENT_PUBLIC_IP=""

curl -H "Content-Type: application/json" \
-H "Authorization: Bearer ${TOKEN}" \
-X POST -d '{
"authorized_users": [
"user1",
"user2"
],
"backups_enabled": true,
"booted": true,
"image": "linode/ubuntu24.04",
"label": "wireguard-server",
"private_ip": true,
"region": "us-southeast",
"root_pass": "${ROOT_PASS}",
"stackscript_data": {
"user_name": "${USERNAME}",
"disable_root": "Yes",
"wireguard_port": "${WIREGUARD_PORT}",
"server_private_ip": "${SERVER_PRIVATE_IP}",
"client_public_key": "${CLIENT_PUBLIC_KEY}",
"client_private_ip": "${CLIENT_PRIVATE_IP}",
"client_public_ip": "${CLIENT_PUBLIC_IP}"
},
"stackscript_id": 00000000000,
"type": "g6-nanode-1",
"tags": ["vpn", "wireguard"],
"disk_encryption": "disabled"
}' https://api.linode.com/v4/linode/instances

```

```
CLI:
export TOKEN="YOUR API TOKEN"
export ROOT_PASS="aComplexP@ssword"
export USERNAME="user1"
export SOA_EMAIL_ADDRESS="user@example.com"
export DOMAIN="example.com"
export SUBDOMAIN="www"
export WIREGUARD_PORT="51820"
export SERVER_PRIVATE_IP="10.0.0.1/24"
export CLIENT_PUBLIC_KEY=""
export CLIENT_PRIVATE_IP="10.0.0.2/32"
export CLIENT_PUBLIC_IP=""

linode-cli linodes create \
--image 'linode/ubuntu24.04' \
--private_ip true \
--label wireguard-server \
--root_pass ${ROOT_PASS} \
--booted true \
--stackscript_id 00000000000 \
--stackscript_data '{"user_name": "${USERNAME}","disable_root":"Yes","wireguard_port":"${WIREGUARD_PORT}","server_private_ip":"${SERVER_PRIVATE_IP}","client_public_key":"${CLIENT_PUBLIC_KEY}","client_private_ip":"${CLIENT_PRIVATE_IP}","client_public_ip":"${CLIENT_PUBLIC_IP}"}' \
--region us-east \
--type g6-nanode-1 \
--tags vpn,wireguard \
--authorized_keys "ssh-rsa AAAA_valid_public_ssh_key_123456785== user@their-computer" \
--authorized_users "user1" \
--authorized_users "user2" \
--disk_encryption disabled
```
